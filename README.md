# VoIPBin Talk (Android)

Official download page for the VoIPBin Talk Android app.

## Install
1. Download the latest `voipbin-talk.apk` from the Releases page.
2. Verify the checksum (see below).
3. Open the file on your Android device and allow
   "Install unknown apps" for your browser or file manager when asked.

Requires Android 8.0 (API 26) or later.

## Verify the download
Each release lists the SHA-256 of the APK in its notes.
  sha256sum voipbin-talk.apk      (Linux; macOS: shasum -a 256)
  Get-FileHash voipbin-talk.apk   (Windows PowerShell)
The value must match the release notes exactly.
